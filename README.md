# Near

Near is a location-based mobile application designed to help travelers discover and reconnect with people they have crossed paths with while travelling.

The app is currently under active development.

## Tech Stack

- React Native
- Expo
- TypeScript
- Supabase
- PostgreSQL
- Google Maps Platform

## Features

Currently implemented:

- User authentication
- User profiles
- Profile pictures
- Interactive map
- Location-based functionality
- Friends system
- Friend requests
- Visited countries
- User search
- Light and dark themes
- Location and notification preferences

## How it works

Near uses location data to create location-based interactions between users. The goal is to allow travelers to discover when they have been in the same places and make it easier to reconnect without building the experience around traditional social-media feeds, posts or likes.

Supabase is used for authentication, user data and backend services, while the mobile client is built with React Native and Expo.

## Project Status

🚧 **Work in progress**

Near is currently being actively developed. Some functionality and UI elements are still being implemented or refined.

## Running locally

Clone the repository:

```bash
git clone https://github.com/mimmofirenze/Near.git
cd Near
```

Install dependencies:

```bash
npm install
```

Create a `.env` file with the required environment variables and start the development server:

```bash
npx expo start
```
